> A desktop music player built with Rust that does what I want from one. Open source!

Backstop v3 is currently under development. Please refer to the current version's page unless you're looking to compile v3 and run it yourself.

# Compiling Backstop v3 from Source

1. Clone the repo
2. Switch to the v3 branch
3. Pull
4. Run `cargo run` or your preferred cargo build command (`cargo build --release` is good)

Alternatively, copy and paste the following into your terminal:
```bash
git clone https://github.com/iwantpizza10/backstop
cd backstop
git checkout v3
git pull
cargo run
```
